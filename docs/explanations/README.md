# Explanations

Explanations provide background, context, and discussion to help readers understand the project's design and decisions.

## Architecture Decision Records

Architecture Decision Records (ADRs) document significant architectural decisions, including the context, options considered, chosen decision, and consequences. Store ADRs in [`adr/`](adr/) and link each record below as it is added. Number ADRs sequentially, for example `0001-example-decision.md`.
