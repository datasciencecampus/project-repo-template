# Documentation

This documentation follows the [Diataxis](https://diataxis.fr/) framework. Diataxis organises documentation by the reader's needs:

- [Tutorials](tutorials/): guided lessons for learning the project.
- [How-to guides](how-to/): practical steps for completing a specific task.
- [Reference](reference/): precise information about the project's APIs, configuration, and data.
- [Explanations](explanations/): background and context that support deeper understanding.

Each section contains an index linking to the documents in that category.
