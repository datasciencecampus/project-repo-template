# Contributing

Thank you for your interest in this repository. At this time, **unsolicited pull requests from external contributors will not be accepted.**

If you have suggestions or feedback, please open an issue to discuss your ideas with the team.

## ONS GitHub Policy

This repository complies with the [ONS GitHub Usage Policy](https://github.com/ONSdigital/software-engineer-community/blob/master/Software%20Engineering%20Principles_Policies_Guidelines_Templates_Plans%20and%20more/Software%20Engineering%20Policies/GitHub%20Usage%20Policy.pdf), which requires:

- **LICENSE** must be included in all public repositories
- **CODEOWNERS** must be configured to identify team or individual ownership
- **Repositories should be public by default**, unless documented in PIRR as private or internal
- **PIRR.md** must be completed for any private or internal repositories
